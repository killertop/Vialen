## 2.1.9：代码健壮性复核

本轮针对 Android 壳层、订阅边界、网络生命周期和 Java 模型做了证据驱动的专项复核，并将确认的问题做最小修复：

- 异步辅助函数改用进程级 `SupervisorJob`；服务连接协程挂到 Binder 生命周期，避免 UI/服务结束后留下无主任务。
- `DefaultNetworkListener` 改为 `Dispatchers.Default` 上的有序无限队列，Connectivity 回调只做非阻塞投递；现有监听器异常隔离和旧回调拒绝语义保留。
- 底层网络与 VPN 服务引用增加跨线程可见性；VPN 更新使用单次快照；旧 Android 已选网络的 DNS 失败不再静默回退到默认网络，避免绕过网络边界。
- 导入目标在“只有订阅组”时通过同库事务创建基本分组；缺少订阅对象的坏分组在刷新开始/提交前按过期请求拒绝，自动调度也跳过该记录。
- 修复 Hysteria 显式传输协议被默认值覆盖的问题，并加入回归测试。

Java 不在本轮移除：Java 代码主要集中在 Bean 序列化兼容层及生成的 sing-box 类型选项，Kotlin 已承担 Android UI、生命周期和业务编排。整批迁移到 Kotlin 或 Go 会扩大持久化兼容和跨层风险；后续若继续优化，只适合按类增量迁移并以字节/配置回归锁定行为。

本轮将版本递增为 **2.1.9 / VERSION_CODE=107**（APK `versionCode=535`）。JVM 回归、Release Lint 和构建通过。随后使用原正式签名生成 Release APK：APK 验签通过，证书指纹与原密钥库一致，公开内容扫描为 0 项；真机安装成功，系统回读包名 `com.vialen.app`、版本 `2.1.9`，首页可启动。全新安装的首页添加入口与四条默认路由已在真机回读，四条规则均启用。

此次未启动 VPN；手机当前 Wi-Fi 关闭且接着外部电源，网络流量、规则下载和第四批性能对照没有续测。原待办 M1–M5、V1–V3 继续按上表保留；已有首页/路由烟测不等于这些专项通过。本地修改不 push、不发布。
